Welcome to the blog. This is where I'll write about agentic AI, multi-agent systems, and the practical side of enterprise AI architecture. Inline references like SKILL.md and README.md render as small code pills, and links look like this one.

How a post is written

Every post is one markdown file in src/blog/posts/. The build reads its frontmatter into a small data object:

{
  "title": "Hello, world: a blog built from markdown",
  "date": "2026-10-18",
  "published": true,
  "position": 1
}

What the build does

  1. Read every file in src/blog/posts/ and parse its frontmatter.
  2. Render the markdown to HTML and highlight code blocks at build time.
  3. Fill the post template and the index template, then publish them.

Why plain HTML and CSS

The best tooling for a small personal site is usually the least tooling you can get away with.

  • Posts should be easy to write in any editor.
  • Pages should load instantly, with no client-side JavaScript.
  • Code, tables, and diagrams should look good without extra effort.

Code and tables

Fenced blocks get syntax highlighting at build time:

// Collect every published post, newest first
import { readdir } from 'node:fs/promises';

async function listPosts(dir) {
  const files = await readdir(dir);
  const count = files.filter((f) => f.endsWith('.md')).length;
  console.log(`Found ${count} posts`);
  return count > 0;
}

# Serve the site on loopback only
cd src && python3 -m http.server 8000 --bind 127.0.0.1 --directory . # then open http://127.0.0.1:8000/blog/
echo "$HOME"
